# 📚 Sistema de Gestão de Biblioteca Universitária — Banco de Dados SQL

Este repositório contém o projeto de modelagem e implementação de um **Banco de Dados Relacional** para a gestão completa de uma biblioteca universitária, desenvolvido no âmbito acadêmico.

O objetivo do sistema é controlar o acervo de livros, cadastro de usuários (alunos e professores), empréstimos, devoluções e penalidades/multas por atraso.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas

* **Modelagem Conceitual/Lógica:** brModelo / Astah UML
* **Ferramenta de Gestão:** SQL Server Management Studio (SSMS)
